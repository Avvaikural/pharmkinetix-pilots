Vancomycin — 1-Compartment IV Bolus

The Model

IV bolus → distributed into Vd (volume of distribution) → eliminated at rate Cl (clearance). One-compartment, first-order elimination.

Assumptions: instantaneous distribution (single well-stirred compartment) · open system (all drug eventually leaves) · linear (concentration-independent PK) · stationary (parameters don't change over the observation period).

AUC-Guided Monitoring (2020 ASHP/IDSA/SIDP)

Vancomycin monitoring shifted from trough-only targets (historically 15–20 mg/L) to an AUC-guided approach. Trough alone correlates imperfectly with total systemic exposure — especially as dosing interval changes — so the guideline instead targets the ratio of total daily exposure to the organism's susceptibility.

MetricEquationTarget
AUC₂₄(24 / τ) × (X₀ / Cl)Total 24-hour exposure at steady state (τ = dosing interval, h)
AUC₂₄ / MICAUC₂₄ / MIC400–600 mg·h/L, assuming MIC ≤ 1 mg/L by broth microdilution

Below 400: risk of treatment failure / resistance. Above 600: increased nephrotoxicity risk. Trough concentration is still sometimes used as a practical surrogate, but AUC₂₄/MIC is now the primary target.

Note: AUC₂₄ assumes steady state across multiple doses, so it isn't directly computed in the current Simulation tab, which focuses on single-dose numbers (C₀, C(t), AUC per dose). This becomes directly usable once multiple-dose regimens are covered later in the course.
